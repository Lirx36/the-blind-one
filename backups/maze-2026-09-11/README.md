# Hollow Labyrinth standalone backup

`TheBlindOne-Labyrinth-v2.rbxlx` is a complete Roblox Studio place generated
from the repository source on 2026-09-11. It contains the roofed 19x19 maze,
gameplay scripts, UI, monster logic, Photo Mode flight, survivor jump lock,
weather, fog, flashlight, objectives, mechanisms, and throwable system.

## Restore without Rojo

1. Clone or download this repository from GitHub.
2. Open `TheBlindOne-Labyrinth-v2.rbxlx` directly in Roblox Studio.
3. Start the Roblox Studio MCP plugin and connect Codex.
4. Save the place under a new name before MCP edits.

The previous city map is separately preserved in
`backups/city-2026-09-11/TheBlindOne-City.rbxlx`.

The `src/` folder remains the readable source of truth and can be used to
inspect or reconstruct any scripts even when Rojo is no longer installed.
