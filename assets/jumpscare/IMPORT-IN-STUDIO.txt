THE BLIND ONE JUMPSCARE IMAGE

Source image:
  blind-one-jumpscare-v1.png

To make Roblox display it:
1. In Roblox Studio, open View > Asset Manager.
2. Open Images, then choose Import or Add Image.
3. Select blind-one-jumpscare-v1.png from this folder.
4. Copy the uploaded image's asset ID.
5. Open src/ReplicatedStorage/Config.luau.
6. Set JumpscareImage to "rbxassetid://YOUR_ID".

Until the ID is filled in, the jumpscare automatically uses a close-up 3D
clone of The Blind One. In a Studio playtest, press J to preview the effect.
