THE BLIND ONE JUMPSCARE IMAGE

The screenshot with rows such as "Premium..." and "Rainbow color..." is the
Toolbox inventory/model list. Those warning triangles are unrelated assets and
are not errors from this game.

Import the jumpscare through the current experience instead:

1. Stop the playtest.
2. Make sure this place is published/connected to the correct Roblox experience.
   Asset Manager cannot manage experience assets from an unpublished local file.
3. In Studio choose File > Import.
4. Select this file:
      assets/jumpscare/blind-one-jumpscare-v1.png
5. Finish the import/upload and wait for moderation.
6. Restart the playtest and press J.

No numeric asset ID is required. The game refers to it by name as:
  rbxgameasset://Images/blind-one-jumpscare-v1

If Roblox has not approved or loaded it yet, the effect safely uses the live 3D
monster portrait instead of displaying a blank image.
